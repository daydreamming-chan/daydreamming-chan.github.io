# 标题

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

# 强调

```
斜体：*星号* 或 _下划线_
粗体：**星号** 或 __下划线__
删除线：~~删除内容~~
```

**这是粗体文本**

*这是斜体文本*

~~删除线~~

# 列表

```
1. 有序列表第一项
2. 有序列表第二项
   - 无序子列表
* 无序列表可以使用星号
- 或减号
+ 或加号
```

1. 有序列表第一项
2. 有序列表第二项
   - 无序子列表

- 无序列表示例
- 另一项

# 任务列表

```
- [x] 完成的事项
- [ ] 未完成的事项
```

- [x] 已完成的事项
- [ ] 未完成的事项
